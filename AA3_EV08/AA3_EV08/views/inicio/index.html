Sobre el proyecto

Este proyecto busca desarrollar un sistema para la gestión de productos de una tienda de frutas y verduras.

El sistema permitirá organizar la información de los productos, sus categorías y proveedores.

Productos

El sistema permitirá administrar productos como frutas, verduras y tubérculos.

  • Frutas
  • Verduras
  • Tubérculos
